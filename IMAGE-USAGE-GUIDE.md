## Resolution note

Kept campaign files are roughly 940–1536 px on the long side. New files are 720×1280, 864×1152, or 1024×1024. They are sharp enough for mobile. On a large desktop hero, prefer role 01, 02, or 23, which are the larger files.

## Overlay rule

None of these files contain website headlines, prices, or buttons. Product monograms and the base script are part of the object. Add UI type in the empty areas listed above.
